# Project Statement

## Project title

Random Password Generator

## Why I made this project

People often create passwords by hand, and it is easy to end up with something short or predictable. I wanted a simple command-line program that could generate a password for the user and also show a few basic checks for password strength.

## What the project covers

The program includes:

- random password generation
- user-selected password length
- uppercase, lowercase, number, and symbol options
- basic password-strength checking
- input validation
- temporary session history
- automated tests

It does not handle user accounts, online storage, password syncing, or a permanent password vault.

## Intended users

The project is mainly suitable for students learning Python and for anyone who wants a small command-line example of password generation and validation.

## Main functions

1. Generate a random password.
2. Choose its length and character groups.
3. Check the strength of an existing password.
4. Show suggestions for missing strength checks.
5. View passwords generated during the current session.
6. Run the automated tests.
