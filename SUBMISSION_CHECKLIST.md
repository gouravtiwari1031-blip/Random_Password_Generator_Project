# GitHub Submission Checklist

Before uploading the project, I would check the following:

- [x] README and project statement included
- [x] Source code included
- [x] Five Python modules with separate responsibilities
- [x] Input validation and error handling
- [x] Automated tests
- [x] Architecture and workflow documentation
- [x] UML/design diagrams
- [x] Project report
- [x] `requirements.txt`
- [x] `.gitignore`
- [x] `LICENSE`

## Before pushing to GitHub

1. Run the program once and make sure the menu works.
2. Run the test command and check that all tests pass.
3. Make sure no real password or personal information is stored in the source code.
4. Do not commit screenshots containing real passwords.
5. Fill in the student details in the project report.
6. Create the GitHub repository and push the project.
7. Open the repository on GitHub and check that the README renders correctly.

## Commands

Run the application:

```bash
python src/main.py
```

Run the tests:

```bash
python -m unittest discover -s tests -v
```
